# Lavacar Geovani — Estetica Automotiva Premium

Landing page profissional desenvolvida para o **Lavacar Geovani**, localizado no bairro Lagoa. O projeto foi focado em alta performance (PageSpeed), SEO local e otimizacao de conversao (CRO) para agendamentos via WhatsApp.

## 🚀 Tecnologias Utilizadas
- **HTML5** semantico com meta tags para SEO local.
- **CSS3** puro (Vanilla CSS) com variaveis, efeito Glassmorphism e animacoes suaves.
- **JavaScript** leve para controle de scroll e interacoes.

## ⚡ Performance & Otimizacao
- 100% Vanilla JS/CSS (sem bibliotecas ou frameworks pesados).
- Fontes otimizadas com `display=swap` e `preconnect`.
- Carregamento instantaneo sem layout shifts (CLS baixo).
